API Documentation v1.0

Simple REST API for file uploads

Base URL
POST /api/v1/upload — Upload a file
Upload a file and receive a temporary download URL. Files are automatically deleted after 10 minutes.
cURL Example 
curl -X POST -F "file=@yourfile.txt" https://your-domain.com/api/v1/upload
Success Response (200) 
{
    "status": "success",
    "data": {
        "url": "https://your-domain.com/dl/1704825600000/yourfile.txt",
        "expires_in": 600
    }
}
Error Response (400/413/500) 
{
    "status": "error",
    "message": "No file provided" | "File too large. Max 20MB" | "Internal server error"
}
GET /dl/{id}/{filename} — Download a file
Download a file using the URL provided after upload. Returns 404 if the file has expired or doesn't exist.
cURL Example 
curl -O https://your-domain.com/dl/1704825600000/yourfile.txt
Error Response (404) 
{
    "status": "error",
    "message": "File not found or expired"
}
